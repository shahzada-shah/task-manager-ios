# Repo setup

1. Create a public repo named `kazi-tasks`.
2. Open the unzipped `kazi-tasks-github` folder and select everything inside it (`README.md`, `LICENSE.md`, `CREDITS.md`, `docs`, `media`). Drag those items, not the folder, onto "Add file → Upload files". Commit message: `Add public page for KAZI Tasks`.
3. Settings → General → Social preview → upload `media/social-preview.png`.
4. About (gear icon):
   - Description: `A tasks app that stays on your iPhone · SwiftUI · WidgetKit · no account, no cloud, no tracking · by KAZI Digital Studio`
   - Website: the App Store link
   - Topics: `swiftui`, `swift`, `ios`, `iphone-app`, `widgetkit`, `app-intents`, `todo-app`, `task-manager`, `productivity`, `privacy`, `offline-first`, `mascot`
   - Untick Releases, Packages and Deployments.
5. Pin the repo on your profile.

Source boards for every image: `KAZI Tasks GitHub Showcase.dc.html` in the design project.
